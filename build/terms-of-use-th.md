# เงื่อนไขการใช้งาน กนก ออฟฟิศ (รุ่นแจกฟรี)

**ฉบับที่ 1 · มีผลตั้งแต่วันที่เผยแพร่รุ่นนี้**

**1. ผู้แจกและขอบเขต**
- บริษัท เอ็นเอแอลแอลทีซี จำกัด ("บริษัท") แจกโปรแกรมกนก ออฟฟิศ รุ่น 1.x ("โปรแกรม") ให้ใช้ได้โดยไม่มีค่าใช้จ่าย
- เงื่อนไขนี้ใช้กับโปรแกรมที่ท่านได้รับผ่านลิงก์ดาวน์โหลดบน kanokoffice.com และกับสำเนาที่ผู้อื่นแจกต่อให้ท่านตามข้อ 3
- เงื่อนไขที่ใช้กับสำเนาของท่าน คือฉบับที่มาพร้อมรุ่นที่ท่านได้รับ

**2. สัญญาอนุญาตโอเพนซอร์ส**
- โปรแกรมพัฒนาต่อจาก LibreOffice
- ส่วนใหญ่อยู่ภายใต้ Mozilla Public License 2.0 ส่วนอื่นอยู่ภายใต้สัญญาอนุญาตตามรายการใน "ข้อมูลสัญญาอนุญาต" ของโปรแกรม
- สิทธิของท่านตามสัญญาอนุญาตเหล่านั้นไม่ถูกจำกัดโดยเงื่อนไขนี้ ซึ่งรวมถึงสิทธิได้รับซอร์สโค้ด แก้ไข และแจกต่อ
- หากเงื่อนไขนี้ขัดกับสัญญาอนุญาตโอเพนซอร์สของส่วนใด ให้ใช้สัญญาอนุญาตนั้นสำหรับส่วนนั้น
- ซอร์สโค้ดดาวน์โหลดได้ฟรีที่ https://kanokoffice.com/source

**3. ชื่อและตรา**
- ชื่อ "กนก" "กนก ออฟฟิศ" "Kanok Office" และตราที่ใช้กับโปรแกรมเป็นของบริษัท
- สัญญาอนุญาตโอเพนซอร์สไม่ได้ให้สิทธิในชื่อและตราเหล่านี้
- ท่านแจกต่อตัวติดตั้งที่ไม่ได้แก้ไขได้ภายใต้ชื่อเดิม
- สิทธิแจกต่อส่วนประกอบของ Microsoft (ข้อ 10) มีเฉพาะเมื่อท่านแจกตัวติดตั้งของบริษัททั้งชุดโดยไม่แก้ไข และแจกพร้อมเงื่อนไขนี้ ถ้าแจกฉบับที่แก้ไข ท่านต้องเอาส่วนประกอบของ Microsoft ออก หรือมีสิทธิแจกของท่านเองจาก Microsoft
- ถ้าแจกต่อฉบับที่แก้ไข ต้องเอาชื่อและตราของกนกออก และต้องไม่ทำให้ผู้อื่นเข้าใจว่าเป็นโปรแกรมของบริษัท
- "LibreOffice" เป็นเครื่องหมายการค้าของ The Document Foundation ซึ่งไม่เกี่ยวข้องกับบริษัทและไม่ได้รับรองโปรแกรมนี้

**4. ข้อควรรู้ก่อนใช้**
- โปรแกรมเปิดและบันทึกไฟล์ของโปรแกรมอื่นได้ แต่รูปแบบและการจัดหน้าอาจไม่ตรงกับต้นฉบับทุกประการ
- โปรดตรวจเอกสารสำคัญก่อนส่งหรือพิมพ์ และสำรองไฟล์สม่ำเสมอ
- แม่แบบหนังสือราชการในโปรแกรมเป็นตัวช่วยจัดรูปแบบ ผู้ใช้ต้องตรวจความถูกต้องตามระเบียบที่ใช้กับหน่วยงานของตนเอง
- รุ่นนี้ไม่มีลายเซ็นดิจิทัล
  - โปรดดาวน์โหลดผ่านลิงก์บน kanokoffice.com เท่านั้น และตรวจค่า SHA-256 ที่ประกาศไว้บนหน้านั้น
  - บริษัทไม่รับผิดชอบต่อสำเนาที่ได้จากแหล่งอื่นซึ่งอาจถูกดัดแปลง

**5. ไม่มีการรับประกัน**
- บริษัทแจกโปรแกรมตามสภาพที่เป็นอยู่โดยไม่คิดค่าใช้จ่าย
- เท่าที่กฎหมายอนุญาต บริษัทไม่รับประกันว่า:
  - โปรแกรมจะปราศจากข้อบกพร่อง หรือทำงานได้ต่อเนื่อง
  - โปรแกรมจะเปิดหรือบันทึกไฟล์ของโปรแกรมอื่นได้ถูกต้องครบถ้วน
  - โปรแกรมจะเหมาะกับวัตถุประสงค์เฉพาะของท่าน
- ผู้ร่วมพัฒนา LibreOffice และซอฟต์แวร์โอเพนซอร์สอื่นในโปรแกรมไม่ได้ให้คำรับประกันใด ๆ แก่ท่าน
- หากในอนาคตบริษัทเสนอการรับประกันหรือบริการแบบมีค่าตอบแทน คำรับประกันหรือบริการนั้นเป็นของบริษัทแต่ผู้เดียว

**6. ข้อจำกัดความรับผิด**
- เท่าที่กฎหมายอนุญาต บริษัทไม่ต้องรับผิดต่อความเสียหายทางอ้อมหรือความเสียหายพิเศษ เช่น การสูญเสียกำไร การหยุดชะงักของงาน หรือข้อมูลสูญหาย
- ความรับผิดรวมของบริษัทเกี่ยวกับโปรแกรมไม่เกิน 1,000 บาท
- ข้อจำกัดในข้อนี้ **ไม่ใช้กับ**:
  - (ก) ความเสียหายต่อชีวิต ร่างกาย หรืออนามัย ที่เกิดจากการกระทำโดยจงใจหรือประมาทเลินเล่อของบริษัท
  - (ข) ความรับผิดเพื่อกลฉ้อฉลหรือความประมาทเลินเล่ออย่างร้ายแรงของบริษัท
  - (ค) ความรับผิดที่กฎหมายห้ามยกเว้นหรือจำกัด

**7. ข้อมูลในเครื่องของท่าน**
- โปรแกรมเปิดและบันทึกเอกสารในเครื่องของท่าน
- โปรแกรมไม่ส่งข้อมูลการใช้งานหรือเนื้อหาเอกสารของท่านมาที่บริษัท และไม่ตรวจหารุ่นใหม่ทางอินเทอร์เน็ตเอง
- การเก็บข้อมูลบนเว็บไซต์ kanokoffice.com เป็นไปตามนโยบายความเป็นส่วนตัว

**8. การเปลี่ยนแปลงเงื่อนไข**
- บริษัทอาจออกเงื่อนไขฉบับใหม่สำหรับรุ่นถัดไป
- ฉบับใหม่ไม่ย้อนไปใช้กับสำเนาที่ท่านได้รับก่อนหน้า

**9. กฎหมายที่ใช้**
- เงื่อนไขนี้อยู่ภายใต้กฎหมายไทย
- ถ้ามีฉบับแปล ให้ถือฉบับภาษาไทยเป็นหลัก
- ข้อนี้ไม่ใช้กับสัญญาอนุญาตโอเพนซอร์ส ซึ่งเป็นไปตามตัวบทของสัญญานั้นเอง

**10. ส่วนประกอบของ Microsoft**
- ตัวติดตั้งมีไลบรารี Microsoft Visual C++ Runtime ("ส่วนประกอบของ Microsoft") ซึ่งบริษัทแจกต่อตามสิทธิที่ Microsoft Corporation ให้ไว้
- ส่วนประกอบของ Microsoft ไม่ใช่ซอฟต์แวร์โอเพนซอร์ส และไม่อยู่ภายใต้สัญญาอนุญาตในข้อ 2
- ท่านใช้ส่วนประกอบของ Microsoft ได้เพื่อเรียกใช้โปรแกรมเท่านั้น ส่วนประกอบนี้เป็นการอนุญาตให้ใช้ ไม่ใช่การขาย และ Microsoft กับผู้จัดหาของ Microsoft สงวนสิทธิอื่นทั้งหมด
- ท่านต้องไม่:
  - (ก) หลบเลี่ยงข้อจำกัดทางเทคนิคของส่วนประกอบนี้
  - (ข) ทำวิศวกรรมย้อนกลับ ถอดรหัส หรือแยกส่วน เว้นแต่เพียงเท่าที่กฎหมายที่ใช้บังคับให้สิทธิแก่ท่านแม้มีข้อจำกัดนี้
  - (ค) ลบ ย่อ ปิดบัง หรือแก้ไขข้อความแจ้งของ Microsoft หรือผู้จัดหาของ Microsoft
  - (ง) ใช้ส่วนประกอบนี้ในทางที่ขัดต่อกฎหมาย
  - (จ) แบ่งปัน เผยแพร่ ให้เช่า หรือให้ยืมส่วนประกอบนี้แยกจากโปรแกรม เสนอเป็นรายการต่างหาก หรือนำไปรวมกับโปรแกรมอื่นเพื่อให้ผู้อื่นใช้
  - (ฉ) โอนส่วนประกอบนี้หรือสิทธิตามข้อนี้แก่บุคคลอื่น เว้นแต่โดยการแจกต่อตัวติดตั้งทั้งชุดตามข้อ 3
- ท่านต้องปฏิบัติตามกฎหมายและข้อบังคับเรื่องการส่งออกที่ใช้กับส่วนประกอบนี้
- เท่าที่กฎหมายอนุญาต Microsoft และผู้จัดหาของ Microsoft ไม่ให้คำรับประกันใด ๆ และไม่ต้องรับผิดต่อท่านเกี่ยวกับส่วนประกอบนี้
- ผู้ที่ได้รับตัวติดตั้งต่อจากท่านต้องอยู่ภายใต้ข้อนี้เช่นเดียวกับท่าน
- ข้อนี้ใช้กับส่วนประกอบของ Microsoft เท่านั้น และไม่จำกัดสิทธิตามสัญญาอนุญาตโอเพนซอร์สในข้อ 2
